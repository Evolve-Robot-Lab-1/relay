# Relay global growth playbook

Operational companion to the Relay Global Business Outreach & Scale Plan.

## Positioning

**Promise:** Know what to say—on any website—without Relay sending for you.

**Wedge ICP:** Global remote professionals, freelancers, founders, and SDRs—especially non-native English writers—on WhatsApp, Gmail, LinkedIn, Slack, and AI chats.

## Phase checklist

1. Trust gate — [extension/TRUST_GATE.md](../extension/TRUST_GATE.md)
2. Package — `npm run extension:package`
3. Waitlist — https://relay.durgaai.com/waitlist
4. Cohorts A/B/C — invite from waitlist storage; collect only draft accuracy, tone fit, confusion, site breakage
5. Public CWS SEO — [extension/STORE_LISTING.md](../extension/STORE_LISTING.md) + use-case pages under `/use/*`
6. Partners — https://relay.durgaai.com/partners and [PARTNERS.md](./PARTNERS.md)
7. Monetize — https://relay.durgaai.com/pricing after D7 ≥30% and weekly Insert habit

## North-star metrics

- D1 / D7 extension return
- Successful Insert or Copy per active user / week
- Top converting sites
- Chrome Web Store rating velocity (target ≥4.5)
- Invite → install → first draft in <10 minutes

## Cohort targets

| Cohort | Code | Success |
|---|---|---|
| Non-native English pros | `non_native_pro` | D7 ≥35%, weekly Insert ≥5 |
| Founders / freelancers | `founder_freelancer` | Would recommend ≥50% |
| SDR / outbound | `sdr_sales` | Self-reported draft time cut ≥40% |

## Messaging kit

- Works inside WhatsApp, Gmail, LinkedIn, Slack, AI chats
- Preserves meaning; user approves Insert/Copy
- No recipient install required

## Kill criteria

Pause outreach on invented facts, private leakage, auto-send perception, adapter rot, or cost blowups on free compose.
