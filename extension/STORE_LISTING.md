## Detailed description

Relay is a context-aware communication copilot. It understands your instruction and the active conversation, then helps draft the next message, reply, post, or prompt inside the website you already use.

How it works:
1. Focus a writing field and open the Relay chip.
2. Improve what’s already there, give a short instruction, or ask Relay to suggest the next reply from conversation context.
3. Review the preview, then Insert or Copy. Relay never presses Send.

Built for high-stakes everyday writing:
- WhatsApp Web replies with quoted-message context
- Gmail and Outlook follow-ups
- LinkedIn DMs and Slack messages
- ChatGPT, Claude, and other AI prompt boxes

Trust boundaries:
- You approve every draft before it touches the page
- Focused context is read only after you open Relay
- Message content is not saved by Relay
- Password, payment, and identity fields are excluded

## Single purpose

Relay helps users write clearer messages, replies, and prompts in eligible writing fields. It does not browse the open web on the user’s behalf, does not send messages automatically, and does not collect browsing history.
