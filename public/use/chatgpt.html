Use case

Improve ChatGPT prompts from rough thoughts

Relay structures your request from what you already wrote. It does not invent requirements or answer the prompt itself.

Flow

  • Type a messy prompt in ChatGPT, Claude, or Gemini.
  • Open Relay → Improve.
  • Insert the clearer prompt, then submit in the AI product yourself.

Prompt pack examples

  • Rough: “make a plan for launch” → goal, constraints, output format only if you supplied them
  • Rough: “fix this email” → preserve facts; no invented warmth
  • Rough: “compare these 2 options” → structured comparison request without inventing criteria
