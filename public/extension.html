Install in Chrome

  1. Download and unzip relay-extension.zip.
  2. Open chrome://extensions and enable Developer mode.
  3. Choose Load unpacked and select the unzipped relay-extension folder.
  4. Refresh WhatsApp, Gmail, or another test site. Open Relay beside a writing field.
